# Data (not tracked in git)

| Path | Source |
|---|---|
| `data/train.csv`, `data/test.csv`, `data/sample_submission.csv` | `kaggle competitions download -c playground-series-s6e10` |
| `data/orig/train.csv`, `data/orig/test.csv` | `kaggle datasets download teejmahal20/airline-passenger-satisfaction` |
| `data/pub_subs/` | public notebook outputs used for the public-LB blends (downloaded with `kaggle kernels output <ref>`); see `docs/JOURNAL.md` for each ref |
